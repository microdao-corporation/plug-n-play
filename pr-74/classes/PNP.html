    Class PNP

    Main PNP (Plug N Play) class for managing wallet connections on the Internet Computer. Supports multiple wallet adapters including Internet Identity, Plug, NFID, and cross-chain wallets through SIWS (Solana) and SIWE (Ethereum) extensions.

    PNP

    Example

    // Create PNP instance with configuration
    const pnp = createPNP({
      network: 'ic',
      adapters: {
        ii: { enabled: true },
        plug: { enabled: true }
      }
    });

    // Connect to a wallet
    const account = await pnp.connect('ii');

    // Get an actor for canister interaction
    const actor = pnp.getActor({ canisterId: 'ryjl3-tyaaa-aaaaa-aaaba-cai' });
